## 6. Measurement protocol (hard-won — follow it)

- **Exclusive host** for any timing (concurrent GPU work = 2×+ contamination;
  proven twice). Production = cards 2,3; benchmarks = 0,1 (scripts pin
  HIP_VISIBLE_DEVICES). TP4 runs need everything idle.
- **Shape-matched warmups** (2+) before believing any number; first request
  at a fresh shape pays JIT/autotune.
- Compile cache `/root/.cache/vllm/torch_compile_cache`: keep warm; purge ONLY
  when traced code changes. Each distinct config hash = one ~15–20 min cold
  start (graph capture is never cached; FULL_DECODE_ONLY keeps it ~13 s).
- Honest decode rates: `verify/decode-rate.py` (streams, excludes prefill).
  Correctness gate: `verify/validate.py --save/--compare` (8 prompts).
- 80-tok short-probe `tok/s` includes prefill — comparability anchor only.
